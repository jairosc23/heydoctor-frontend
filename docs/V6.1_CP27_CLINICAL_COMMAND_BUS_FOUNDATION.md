# v6.1 CP-27 — Clinical Command Bus Foundation

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-27 — Clinical Command Bus Foundation  
**Normativo:** CP-25 Store + CP-26 Realtime (sin modificar)

## Objetivo

Capa unificada para representar cualquier interacción del usuario como un `ClinicalCommand`.

```text
UI / Keyboard / Mouse / Shortcuts / Voice* / Automation*
                    ↓
          Clinical Command Bus
                    ↓
         Command Handlers → Effects
                    ↓
         Ports (inyectados, futuro)
                    ↓
         MedicalCopilotStore / Facade API
```

\* Voice no implementado en CP-27 — solo `source: "voice"` soportado en el contrato.

## Comandos iniciales

- `bootstrap_session`
- `refresh_workspace`
- `approve_action`
- `reject_action`
- `open_workspace`
- `open_timeline`
- `open_memory`
- `open_actions`

## Reglas

- Handlers no ejecutan lógica clínica
- Handlers no llaman backend
- Handlers no importan Store / Provider / Realtime
- `source` nunca se reenvía a ports (Store origin-agnostic)
- Ports opcionales: sin attach → `executed: false`

## Preparación CP-28

Voice Copilot emitirá los mismos `ClinicalCommand` (`source: "voice"`) hacia el Bus, sin acoplar UI ni Store.

# v6.1 CP-28 — Voice Session Manager Foundation

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-28 — Voice Session Manager Foundation  
**Normativo:** CP-27 Voice Copilot Foundation (sin modificar `VoiceCopilotService`)

## Objetivo

Gestor del ciclo de vida de una sesión de voz, desacoplado del Store y de engines reales.

```text
VoiceCopilotService (CP-27, sin cambios)
        ↓ (integración futura)
VoiceSessionManager (CP-28)
        ↓
VoiceTransportProvider mock
        ↓
Future engines (CP-29+)
```

## Lifecycle

```text
idle → created → starting → listening ⇄ paused
                      ↓           ↘ timed_out
                 processing → completed
                      ↘ cancelled
                      ↘ error → recovering → created
```

## Capacidades

- crear / iniciar / pausar / reanudar / completar / cancelar
- timeout (clock inyectable)
- recuperación de error / timeout
- cambio de engine (lógico)
- estado de permisos (lógico, sin prompt real)

## Preparación CP-29

Speech Provider Integration puede sustituir el mock transport sin cambiar el contrato del Session Manager.

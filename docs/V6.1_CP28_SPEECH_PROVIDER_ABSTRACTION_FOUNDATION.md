# v6.1 CP-28 — Speech Provider Abstraction Foundation

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-28 — Speech Provider Abstraction Foundation  
**Normativo:** CP-27 Voice Copilot Foundation (sin modificar `VoiceCopilotService`)

## Objetivo

Desacoplar el motor de voz del resto de la aplicación mediante un contrato único.

```text
VoiceCopilotService (sin cambios)
        ↓ (futuro)
SpeechProvider  ←── SpeechProviderFactory
        ↑
SpeechProviderRegistry
        ↓
mock (ready) | web_speech | openai_realtime | deepgram | azure | google (stubs)
```

## Contrato

Todos los proveedores implementan `SpeechProvider`:

- `start` / `stop` / `cancel` / `onEvent`
- `asTransport()` → `VoiceTransportProvider` (puente CP-27)
- `capabilities` / `status` / `id` / `kind`

## CP-28 runtime

| Provider | status | implemented |
|----------|--------|-------------|
| mock | ready | true |
| resto | unconfigured | false (stubs) |

Sin audio real, sin APIs externas, sin streaming.

## Preparación CP-29 / CP-30

Voice Pipeline normaliza eventos del provider; CP-30 puede registrar el primer engine real (`implemented: true`) emitiendo hacia el Pipeline sin cambiar Service ni Store.

# v6.1 CP-30 — Web Speech Provider Integration (Development Foundation)

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-30 — Web Speech Provider Integration  
**Normativo:** CP-28 SpeechProvider + CP-29 VoicePipeline (interfaces sin cambios)

## Objetivo

Primer Speech Provider funcional con Web Speech API del navegador, para validar la arquitectura Voice.

```text
Micrófono (browser)
        ↓
Web Speech API
        ↓
WebSpeechProvider  →  SpeechProvider contract
        ↓
attachSpeechProviderToVoicePipeline
        ↓
VoicePipeline
```

## Feature detection + fallback

- `isWebSpeechApiAvailable()`
- `resolveWebSpeechProvider()` → Web Speech si hay API; si no, **MockProvider**
- Registry: `web_speech` `implemented: true`

## No incluido

Deepgram · OpenAI Realtime · Azure · Google · streaming remoto · cambios a Service/Store

## Preparación CP-31

Dictado clínico puede consumir transcripts del Pipeline (`final_transcript` / `partial_transcript`) sin acoplarse al motor.

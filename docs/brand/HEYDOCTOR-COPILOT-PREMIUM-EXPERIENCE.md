## Purpose

Collect all **post-launch UX refinements** for HeyDoctor Copilot in a single Product Epic.

This document does **not** authorize implementation by itself.  
It is the engineering backlog SSOT for transforming a **technically complete** product into a **world-class physician experience**.

---

## Success criterion

> Transform HeyDoctor Copilot from a technically complete product into a world-class physician experience.

Comparable *UX coherence* (not feature parity): Microsoft Copilot · GitHub Copilot · Cursor · Claude — immediate product clarity, low cognitive load, premium clinical polish.

---

## Product Epic

**Epic name:** HeyDoctor Copilot Premium Experience  

**Outcome:** Physicians feel a calm, intelligent, trust-forward clinical platform — Insights HOME remains primary; Brand Promise remains identity (not UI spam); authority remains obvious without noise.

## Guardrails

- Brand Promise stays **OFFICIAL / FROZEN** — use sparingly in UI.  
- Clinical Insights remains **HOME**; Assistant remains a **capability**.  
- One product · One identity · One Copilot (Brand Constitution).  
- NON-AUTHORITY · Human-in-the-Loop · Evidence-Driven always ambient.  
- No parallel AI brands.  
- No architecture / runtime / backend / API / governance changes in this Epic unless separately authorized.

---

## Non-goals

- New AI models or clinical capabilities  
- Endpoint / route / contract renames  
- Authority model changes (Confirm / Emit / Apply remain outside Copilot)  
- Implementation tracked in this document alone

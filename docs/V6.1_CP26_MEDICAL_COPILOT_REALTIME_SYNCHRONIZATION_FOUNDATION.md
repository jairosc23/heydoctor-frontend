# v6.1 CP-26 — Medical Copilot Realtime Synchronization Foundation

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-26 — Medical Copilot Realtime Synchronization Foundation  
**Normativo:** CP-25 MedicalCopilotStore (sin modificar)

## Objetivo

Capa de sincronización transport-agnostic entre productores externos y el Store.

```text
REST / SSE* / WebSocket* / Voice*
        ↓
MedicalCopilotRealtimeAdapter
        ↓
RealtimeEventDispatcher
        ↓
MedicalCopilotStore (acciones existentes)
```

\* SSE / WebSocket / Voice: contratos listos; **no activados** en CP-26.

## Eventos

- `workspace_updated`
- `timeline_updated`
- `memory_updated`
- `action_updated`
- `session_updated`
- `connection_state`

## Mapeo a Store (sin cambiar el reducer)

| Evento | Acción(es) Store |
|--------|------------------|
| workspace_updated / timeline_updated | `REFRESH_SUCCESS` (merge vía `getState`) |
| memory_updated | `REFRESH_SUCCESS` (merge; `actions` opcional para sync REST completo) |
| action_updated | `ACTION_UPDATED` |
| session_updated | `BOOTSTRAP_SUCCESS` (merge paneles) |
| connection_state | `SET_DATA_SOURCE` solo si cambia source; estado de conexión vive en el Adapter |

## Transportes

| kind | active |
|------|--------|
| rest | true |
| sse | false (stub) |
| websocket | false (stub) |

## Preparación CP-27

Voice Copilot podrá emitir los mismos `RealtimeEvent` hacia el Adapter **y** `ClinicalCommand` hacia el Command Bus, sin acoplar UI ni modificar el Store.

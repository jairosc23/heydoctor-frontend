# v6.1 CP-25 — Medical Copilot State Management Foundation

**Épica:** v6.1 — Medical Copilot Experience  
**Subfase:** CP-25 — Medical Copilot State Management Foundation  
**Normativo:** CP-24 Frontend Foundation + Facade API CP-23  

## Objetivo

Estado compartido único para la UI del Medical Copilot.

```text
MedicalCopilotProvider
  → medicalCopilotReducer (Store)
  → hooks (useMedicalCopilot / useWorkspace / …)
  → presentation components
```

## Capacidades

- Centraliza session, workspace, timeline, memory, actions, loading, refreshing, errors
- `dataSource: rest | sse | websocket` preparado (REST activo)
- UI desacoplada del fetch directo

## Hooks públicos

- `useMedicalCopilot()`
- `useWorkspace()`
- `useTimeline()`
- `useConversationMemory()`
- `useClinicalActions()`

## Preparación CP-26

Store listo para productores realtime (REST / SSE / WS / Voice) vía Realtime Adapter, sin acoplar componentes al transporte.

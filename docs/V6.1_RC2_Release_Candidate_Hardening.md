## P0 resueltos

### P0-1 — Kill Switch
- Feature flag env: `NEXT_PUBLIC_MEDICAL_COPILOT` (`0`/`false`/`off` → off; vacío → on).
- Runtime reversible: `localStorage hd_mc_kill_switch=1` (sin redeploy).
- UI: `data-testid="medical-copilot-kill-switch"`; no monta shell Copilot.
- No afecta consulta clínica, Workspace base, EMR ni autenticación.

### P0-2 — Session Ownership
- SSOT: `sessionStorage hd_mc_session_ownership_v1` (1 `sessionId` / consulta).
- Bootstrap único vía `bootstrapMedicalCopilotSession` (Workspace/Provider).
- Adapter exige `sessionId`; **nunca** llama `createSession`.

### P0-3 — Auth Recovery
- Ante 401/JWT expirado: ownership **no** se borra.
- Tras re-login / retry: restore de la misma `sessionId` (sin create).
- Sin auto-ejecución de acciones clínicas; HITL intacto.
